## 七、经验总结

### 踩坑

1. **`Map.of` 不允许 null 值** — `Map.of("data", null)` 抛 NPE。包含 null 字段时必须用 `HashMap`/`LinkedHashMap`。

2. **Spring Boot Filter 双重注册陷阱** — `@Component OncePerRequestFilter` 会被自动注册到 servlet 链，同时 SecurityConfig 又 `addFilterBefore` 加入 Security 链 → 双重执行 → response 已 commit 抛 IOException → 500。必须显式 `FilterRegistrationBean.setEnabled(false)` 禁用 servlet 自动注册。

3. **OpenAPI 业务码 → HTTP 码映射混乱** — 原代码用 `code >= 30000 ? 403` 阈值判断，40101 走到 `>=500` 分支 → 500。业务码空间应与 HTTP 语义对齐(401xx→401, 403xx→403, 429xx→429)。

4. **DataIntegrityViolation 在 @Transactional 中** — 数据校验应在 Controller 层前置，不要依赖 DB 异常兜底。

5. **PDF 按范围拆分参数类型歧义** — 接口文档没说清是字符串还是数组。Controller 入口加前置校验，必填 + 类型敏感字段不能裸传 Map。

6. **JwtAuthFilter 的 permitAll 路径漏了 `/ws/` 和 `/actuator/`** — WebSocket 握手和容器健康检查被拦截。白名单必须与 SecurityConfig 的 permitAll 路径保持一致。
