## 摘要

集成 [MindElixir v5](https://github.com/SSShooter/mind-elixir-core)（MIT 协议，国产 GitHub 5.2k+ star）作为项目第 6 种文档类型「思维导图」。支持节点 CRUD / 拖拽 / 撤销重做 / 主题切换 / 导入导出 / 实时协同编辑 / AI 4 个能力（生成/扩写/总结/智能图标）。

## 关键决策

| 维度 | 选择 | 理由 |
|---|---|---|
| 核心组件 | MindElixir v5.15.0 | MIT 协议 + 中文社区最活跃 + 原生 Vue 3 兼容 |
| Vue 集成 | 自封装（不用第三方 wrapper） | `@mind-elixir/vue3` npm 404 |
| 协同 | Yjs 节点级（Y.Map<id, Y.Map> + Y.Map<id, Y.Array<id>>） | 项目已有 yjs/y-websocket；节点级比全树替换体验好 |
| AI 复用 | 后端零改动 + 复用 `/api/ai/chat/stream` + `useAiChat` + `AiPanel` | 节省 ~150 行后端代码 |
| 颜色 | 七彩虹（主色琥珀橙 `#F59E0B` + 7 色节点色板） | 不与已用 5 色冲突，区分度高 |
| 数据格式 | JSON 树（MindElixir 原生），存 `mt_document.filePath` | 与 Markdown 模式一致 |
| 保存策略 | 1.5s 去抖全量保存 | 与 Markdown 模式一致 |
